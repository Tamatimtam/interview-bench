I got sick of HackerRank's 45-second test runner.

So I built a lightweight scratchpad for myself. Whenever an interviewer blindsides me with a weird problem twist, or when I botch a technical round, I document the problem and its edge-case variations here so I actually understand the mechanics.

Everything compiles and executes right in your browser via Pyodide. No queue wait, no sign-in, no remote server ping. If your code accidentally hits an infinite loop (e.g. while True:), a 5-second watchdog worker thread kills it before your browser tab locks up.
